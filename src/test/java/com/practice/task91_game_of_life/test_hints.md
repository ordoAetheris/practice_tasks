# Подсказки: Игра «Жизнь» (task105)

## Обязательно протестировать
- **Блок 2×2** (все живые) — стабилен: после step() поле не меняется.
- **Мигалка (blinker)** — три живые в ряд → после step() три живые в столбец, ещё step() → снова ряд (период 2).
- Одинокая живая клетка → умирает (0 соседей).
- Мёртвая ровно с 3 живыми соседями → оживает.
- aliveCount корректен до и после шагов.

## Границы (суть аккуратности — за это валят)
- Живые клетки в углу/на краю: соседи считаются только внутри поля (не выходить за массив).
- Поле 1×1 (живая → умрёт), поле из одной строки/столбца.
- Пустое/полностью мёртвое поле — остаётся мёртвым.

## Ловушки
- Обновление «на лету»: если менять текущее поле во время подсчёта, клетки увидят уже обновлённых
  соседей → неверный результат. Считать по старому, писать в новый буфер, потом свапнуть.
- Defensive copy начального массива (внешний массив не должен влиять после конструктора).
- Off-by-one в переборе 8 соседей (пропустить саму клетку).
