# Подсказки: рассадка в кинотеатре (task103)

## Обязательно протестировать (edge-кейсы — суть задачи)
- Обычный ряд: `[1,0,0,0,1,0,1]` → индекс 2 (макс. расстояние до ближайшего занятого = 2).
- Занятые только слева: `[1,0,0,0]` → сесть в самый конец (индекс 3).
- Занятые только справа: `[0,0,0,1]` → индекс 0.
- Совсем нет занятых: `[0,0,0]` → сесть с краю (индекс 0).
- Нет свободных: `[1,1,1]` → -1.
- Один элемент: `[0]` → 0; `[1]` → -1.
- Два одинаково хороших места → детерминированный выбор (меньший индекс).

## Динамическая версия
- Серия seat() заполняет места «оптимально» по одному; когда мест нет → -1.
- leave(p) освобождает; следующий seat() может занять освобождённое, если оно лучшее.
- seat/leave вперемешку — состояние консистентно.

## Ловушки
- Расстояние у края считается до ЕДИНСТВЕННОГО соседа (не min из двух — второго нет).
- Off-by-one на границах интервала между двумя занятыми (расстояние = (right-left)/2).
- Пустой массив / null — не упасть.
